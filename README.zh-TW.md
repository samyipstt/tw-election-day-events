# 台灣投票日演出觀測 — 原始資料（第一期：115年地方公職人員選舉）

**[English → README.md](README.md)**

本資料庫是**原始公開資料的發布**，內容包括：台灣 **2026 年 11 月 28 日（六）** 投票日（地方公職人員選舉暨全國性公民投票）列出的演出、各演出掛名的公司，以及這些公司在經濟部商工登記中的董監事與持股；另附 2016 年以來歷屆投票日的日期、原始檔期清單、新聞報導與個別演出資料，以及掛名公司所屬集團的政治獻金登錄摘錄（不標示政黨）。

**本資料庫不含任何分析**：沒有公司分級、事實查核、比較或結論。這些只出現在作者的網頁 <https://www.samyip.net/tw-election-day-events/>，不屬於本發布。

狀態：**正式發表前的資料發布（0.3.0-draft）**。資料屬進行中的研究，將於日後論文中引用；後續版本可能更正數值，請見 `CHANGELOG.md`。

## 資料說明
- **商工登記資料**：2026 年 10 月 15 日擷取自 findbiz 公開頁面，照原樣收錄，包括登記公示的董監事姓名。「股權狀況」空白，表示該登記頁沒有此欄；在擷取的頁面中，只有僑外資或陸資公司才會出現此欄。所擷取的公司均未標示為「陸資」。
- **持股**：多名董事代表同一法人股東時，持股在每列重複列出，加總時只計一次。有限公司的登記只列董事，持股合計可能不足 100%。
- **掛名**：法人無法確認者，`legal_entity_matched` 留空。
- **政治獻金**：照登錄資料摘錄；因無法逐筆確認受贈人捐款當時的黨籍，本檔不標示政黨。
- **檔期清單**：照來源原文列出名稱；不同來源的重複保留，每列為（日期、名稱、來源）。
